# Vanta

**The desktop environment for Sorabbyngo OS.**

Vanta is a lightweight, simple desktop built on a customised [Hyprland](https://hyprland.org). It keeps Hyprland's fluid animations and customisation, and removes the complexity, so anyone can use it without learning a tiling window manager. You talk to your computer by voice or text, and it does the work.

> Status: early design. Nothing here is stable yet.

## What Vanta is for

- **Non-technical users.** It should feel like the desktop you already know: windows, a launcher, a panel, settings. No config files, no terminal needed.
- **AI at the centre.** Give commands by voice or text from anywhere on the desktop.
- **Offline and online.** The desktop and its core AI features keep working without a connection, and get better with one.
- **Light and fast.** Small memory footprint, quick start, smooth on modest hardware.
- **Beautiful by default.** Hyprland-style animations, tuned and ready, with a small set of keyboard shortcuts.

## How it compares

| | GNOME / KDE Plasma | Hyprland | Vanta |
|---|---|---|---|
| Ease for new users | High | Low | High |
| Weight | Heavy | Light | Light |
| Animations | Basic | Excellent | Excellent |
| Built-in AI control | No | No | Yes |
